# Weekly Assignments

A repository containing a series of weekly assignments implemented in Jupyter Notebooks.

## 📋 Contents

This repository includes the following assignments:

- **weekly1.ipynb** - Week 1 Assignment
- **weekly3.ipynb** - Week 3 Assignment
- **weekly4.ipynb** - Week 4 Assignment
- **weekly5.ipynb** - Week 5 Assignment
- **weekly6.ipynb** - Week 6 Assignment
- **weekly7.ipynb** - Week 7 Assignment

## 🚀 Getting Started

### Prerequisites

- Python 3.7 or higher
- Jupyter Notebook or JupyterLab
- Required Python packages (dependencies may vary by assignment)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/sachindra-arch/weekly_assignments.git
   cd weekly_assignments
   ```

2. Install Jupyter if not already installed:
   ```bash
   pip install jupyter
   ```

3. Launch Jupyter Notebook:
   ```bash
   jupyter notebook
   ```

## 📖 How to Use

1. Open any `weekly*.ipynb` file in Jupyter Notebook
2. Read the assignment instructions and requirements
3. Execute the cells to run the code
4. Complete any required tasks or modifications

## 📝 Notes

Each notebook contains:
- Assignment instructions
- Code cells for implementation
- Test cases or expected outputs
- Explanations and documentation
